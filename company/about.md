# GameCompany2 스튜디오 소개

## 비전
> "작은 게임이라도, 플레이어의 손가락에 도파민이 팡팡 터지게."

우리는 거대한 AAA 게임을 만들려 하지 않습니다.
**짧은 세션·즉각적인 보상·수집 욕구**로 모바일에서 손에 잡히는 재미를 만듭니다.

## 원칙
1. **광고 없음.** 플레이어의 몰입을 방해하지 않습니다. 수익은 인앱 아이템으로.
2. **F2P-friendly.** 결제하지 않아도 충분히 즐길 수 있어야 합니다.
3. **코스메틱 우선.** 밸런스를 깨는 P2W은 지양, 외형·편의 위주.
4. **작게 자주 업데이트.** 시즌 패스·이벤트로 리텐션 유지.

## 팀 구성 (4개 역할)
- 🎯 **기획자 (Planner)** — 컨셉·밸런스·수익 모델
- 🎨 **디자이너 (Designer)** — UX·비주얼·사운드 톤
- 💻 **개발자 (Developer)** — Phaser 3 기반 구현·최적화
- 🧪 **테스터 (Tester)** — 회귀 체크·엣지 케이스 발굴

각 역할의 책임과 체크리스트는 [`roles/`](roles/)에서 볼 수 있습니다.

## 협업 흐름
```
기획자  →  디자이너   →  개발자     →  테스터
(PLAN.md)  (DESIGN.md)   (src/*)      (TEST.md)
    ↑_______________feedback loop_______________↓
```
한 사이클이 끝나면 테스터의 체크리스트 결과를 모두 함께 보고
다음 빌드에서 무엇을 고칠지 결정합니다.
