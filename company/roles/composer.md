# ROLE · COMPOSER

> GameCompany2의 5번째 역할. 사운드 디렉터. 모든 게임의 청각적 정체성을 책임진다.

## 책임

- **사운드 정체성(Sound Identity)** — 각 게임의 톤과 분위기를 한 줄로 정의하고 거기 맞는 팔레트(장르·악기·템포)를 제안한다.
- **BGM 디자인** — 씬 전환에 맞춰 자연스럽게 레이어링되는 루프 트랙(메뉴·플레이·결과) 설계. 게임 템포·긴박감·승리감을 음악으로 증폭한다.
- **SFX 설계** — 탭/폭발/콤보/랭크업/결제/밀스톤 등 이벤트별 효과음 톤·타이밍·게인 정의. 스케일·화음을 선택해 누적될 때도 불협이 없도록 한다.
- **믹스 밸런스** — SFX와 BGM이 서로 묻히지 않도록 볼륨 지침(예: BGM 0.15, SFX 피크 0.08).
- **어댑티브 믹싱(선택)** — 콤보·긴박감·레벨 진행에 따라 BGM 레이어를 점진적으로 켜고 끈다.

### 구현 인터페이스
- `shared/audio.js` — Web Audio 기반 SFX/BGM 합성.
  - `Audio.tap / combo / rare / bomb / purchase / milestone / fanfare / rankup` — 이벤트 SFX
  - `Audio.perfect / great / good / linkBonus / levelUp` — 판정 & 보너스 SFX
  - `Audio.playBgm(trackId, { fadeIn })` / `Audio.stopBgm({ fadeOut })` — 트랙 재생 제어
  - `Audio.setMasterGain(v)` / `Audio.setMusicGain(v)` / `Audio.setSfxGain(v)` — 믹스 조절

## 사운드 가이드라인

### 통합 팔레트
- **스케일**: 펜타토닉·마이너 기조 (불협 최소화, 콤보 누적 시에도 안정)
- **파형**: 리드 `triangle`/`sine`, 퍼커시브 `square`, 충격음 `sawtooth` + noise
- **엔벨로프**: 아주 짧은 어택(3~6ms), 지수감쇠 릴리즈로 "깔끔하게 찍히는" 느낌
- **공간감**: 짧은 에코 딜레이(90~160ms, 30% 피드백)로 깊이 추가 가능

### 피드백 원칙
- **PERFECT** — 밝고 맑게. 고음 sine 2음, 5도 또는 옥타브 스택
- **GREAT** — 안정 화음. 3도 하모닉
- **GOOD** — 짧은 블립. 단일음
- **EARLY/LATE** — 소리 거의 없음 또는 저볼륨 썹(감쇠된 저음 sine)
- **MISS** — 낮고 짧은 떨어짐 tone, dry
- **LINK** — 두 음이 동시 발음 후 5도 위로 상승 → 협동감 표현
- **LEVEL UP** — 4음 상행 아르페지오 + 약간의 리버브

### 금지사항
- 길이 300ms 넘는 SFX는 중첩 시 머드해짐. 짧게.
- 절대적 저음 40Hz 미만 지양 (모바일 스피커에서 사라짐).
- BGM 최대 볼륨 > SFX 최소 볼륨이면 SFX가 묻힘. 체크.

## 테스트 체크리스트
- [ ] 모든 SFX가 무음 → 완전 재생 → 조용함 순서로 자연스럽게 끝남 (클릭 노이즈 없음)
- [ ] 30초 연속 탭(콤보 30+)해도 청각 피로 없이 듣기 좋음
- [ ] BGM 루프 연결부가 자연스러움 (끊김/쿵 소리 없음)
- [ ] 씬 전환 시 이전 BGM이 fadeOut, 새 BGM이 fadeIn
- [ ] 모바일(저주파 약함) · 노트북 스피커(고주파 거슬림) 양쪽에서 밸런스 확인
- [ ] 음소거(`Audio.setEnabled(false)`) 토글 동작
