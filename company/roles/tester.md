# 🧪 테스터 (Tester)

## 역할 정의
플레이어가 겪을 **모든 불쾌한 순간**을 출시 전에 먼저 겪어본다.

## 책임
- 정상 플로우(golden path) 회귀 테스트
- 엣지 케이스 발굴 (연타·백그라운드 전환·저장 손상 등)
- IAP 구매 → 재화 반영 → 장착 반영까지 end-to-end 확인
- 성능/배터리 체감 리포트

## 산출물
각 게임 폴더에 **`TEST.md`** 작성:
- **Environments** — 테스트한 브라우저/디바이스 목록
- **Golden Path** — 정상 플레이 체크리스트
- **Edge Cases** — 비정상 입력·상태 체크리스트
- **IAP Cases** — Mock 어댑터 기준 구매 플로우
- **Performance** — 프레임 드랍·메모리 관측치
- **Known Issues** — 재현 단계와 함께 버그 기록

## 기본 체크리스트 템플릿
### 정상 플레이
- [ ] 첫 진입 시 튜토리얼/메뉴가 보인다
- [ ] 핵심 인터랙션이 3초 이내에 파악된다
- [ ] 세션 종료 시 보상이 애니메이션으로 표시된다
- [ ] 재화 증가/감소가 저장된다

### 엣지 케이스
- [ ] 입력 연타 시 크래시 없음
- [ ] 세션 중 탭 전환/백그라운드 후 복귀해도 정상
- [ ] localStorage 비활성/가득찬 상황 graceful fallback
- [ ] 아주 작은 화면 (320px 폭)에서 UI 잘리지 않음
- [ ] 세로/가로 회전 시 정상 표시

### IAP
- [ ] 구매 성공 시 해당 아이템 즉시 반영
- [ ] 구매 취소/에러 시 재화 차감 없음
- [ ] 첫 구매 보너스는 **정확히 1회만** 적용
- [ ] 이미 소유한 코스메틱 재구매 시도 시 안내 후 차단

### 성능
- [ ] 저사양 모바일 브라우저에서도 프레임 드랍 허용 범위
- [ ] 배터리 소모 체감 이상 없음
