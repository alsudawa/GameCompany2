# 🎯 기획자 (Planner)

## 역할 정의
플레이어가 "한 판만 더"를 외치게 만드는 **게임의 뼈대**를 설계한다.

## 책임
- 한 줄 컨셉 · 타겟 세션 시간 · 핵심 재미 축 정의
- 밸런스 표 (속도·배율·보상 컷) 관리
- 수익 모델 (IAP 카탈로그·보상 스케줄) 설계
- 일일/주간 리텐션 루프 설계

## 산출물
각 게임 폴더에 **`PLAN.md`** 작성:
- **Concept** — 게임을 한 줄로 설명
- **Target Session** — 1판 플레이 시간
- **Core Loop** — 입력 → 피드백 → 보상 → 다시 입력
- **Balance Table** — 숫자로 밸런스 명시
- **Monetization** — 상품 카탈로그·전환 후크
- **Retention** — 데일리/주간 스케줄

## 체크리스트 (MVP 전)
- [ ] Core Loop가 3분 이내에 "아, 재밌네"를 주는가
- [ ] 밸런스 수치가 config 파일에 **코드 상수로** 반영되었나
- [ ] 구매 전환 지점이 자연스러운가 (강제·기만 없이)
- [ ] 첫 세션에서 "무엇을 살 수 있는지" 직관적으로 보이는가
- [ ] 과금하지 않은 유저도 **시즌 패스 보상의 50% 이상** 획득 가능한가

## 협업 접점
- 디자이너에게 **화면 위에 어떤 숫자가 언제 보여야 하는지** 전달
- 개발자에게 **config 값 변경 요청 시 수치만 바꾸면 되도록** 구조 요구
- 테스터에게 **밸런스 검증 시나리오** (예: 평균 유저 20판 후 젬 잔액) 제공
