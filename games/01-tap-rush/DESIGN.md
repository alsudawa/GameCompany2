# Tap Rush — 디자인 가이드 (DESIGN.md)

> 작성: 🎨 디자이너

## Visual Direction
**"심야 아케이드 네온".**
짙은 퍼플 블루의 배경 위에 시안·마젠타·골드의 네온이 터진다.
장식보다 대비와 여백. 숫자와 오브가 주인공.

## Typography
- 시스템 기본 산세리프 (Noto Sans KR 우선 fallback)
- 점수: **Bold 48~72px**, 콤보 팝업은 Bold 32~40px
- 본문 UI: 16~18px

## Layout (세로 모드 기준, 480×800 권장)
```
┌──────────────────────────┐   ← 상단 상태바(10%)
│ 🏆 12345      ⏱ 00:45   │
├──────────────────────────┤
│                          │
│      (플레이 영역)        │
│      오브가 낙하          │
│                          │
├──────────────────────────┤   ← 하단 안전영역 (44px 이상)
│  💰 123  💎 42    [설정] │
└──────────────────────────┘
```

- **Thumb Zone**: 화면 하단 55%가 탭이 쉬운 위치. 오브 스폰 Y는 상단 15%에서 시작.
- **Top 10%는 HUD 전용** — 오브와 겹치지 않도록 spawn margin 확보.

## Motion Guide
| 연출 | duration | easing | 비고 |
|---|---|---|---|
| 오브 등장 | 150ms | Back.Out | 살짝 튀어오르며 등장 |
| 탭 터짐 파티클 | 500~700ms | Cubic.Out | 10개 방사형 |
| 숫자 팝업 (+10) | 700ms | Cubic.Out | 위로 50px, 페이드 |
| 콤보 팝업 (COMBO ×3!) | 900ms | Back.Out | 크게 → 작게 |
| 화면 흔들림 | 120ms | — | 강도 = combo×0.002, max 0.015 |
| 레어 슬로모션 | 180ms | — | 타임스케일 0.3 |
| 레어 플래시 | 160ms | — | 골드 풀스크린 |
| 폭탄 플래시 | 200ms | — | 레드 풀스크린 + shake 강 |
| 등급 연출 (S) | 1200ms | Back.Out | 팡파르 + 스파클 |

## Screens
1. **Menu** — 타이틀 로고, START, SHOP, 내 최고점·재화 표시
2. **Game** — 위 레이아웃대로 플레이
3. **Result** — 등급 배지 큰 표시, 점수/콤보 최고치/획득 코인·젬, [다시] [메뉴]
4. **Shop** — 탭(TAB) 3개: Gems / Cosmetics / Pass. 상품 카드, 가격, 구매 버튼

## SFX Tone
- 일반 탭: 짧은 "틱" (square 880Hz 스윕)
- 콤보: 콤보 올라갈수록 피치 상승
- 레어: 종소리 같은 반짝 (sine 1200→2000Hz)
- 폭탄: 둔탁한 "두둑" (sawtooth 200→60Hz)
- 구매 성공: 경쾌한 상승 음
- 팡파르: 3단 상승음 (C→E→G)

## Accessibility
- 폭탄은 색뿐 아니라 **명확히 다른 형태**로 구분 (✕ 심볼)
- 레어는 후광(glow) + 파티클로 색약도 식별 가능
- 버튼 터치 타겟 **최소 44×44**

## 디자인 일관성 체크
- [ ] 네온 3색 외의 hue는 사용하지 않는다
- [ ] 팝업 숫자는 **Bold + 검정 Stroke 4px**로 가독성 확보
- [ ] 버튼은 둥근 모서리 12~16px, 호버/탭 시 살짝 scale 0.95
