# Tap Rush — 기획서 (PLAN.md)

> 작성: 🎯 기획자

## Concept
네온 오브가 위에서 떨어진다. 탭으로 터뜨려 콤보를 쌓고, 60초 안에 최대 점수를 내라.

## Target Session
- **1판 = 60초.** 결과·상점 포함 약 1분 30초
- 유저는 "한 판만 더" 심리로 평균 5~7세션 유지를 목표

## Core Loop
```
입력(탭)
  → 피드백(파티클·숫자팝업·카메라흔들림·효과음)
  → 보상(점수·콤보×배율, 때때로 젬)
  → 60초 종료 → 등급 연출 → 재화 지급
  → "다시!" 또는 상점/스킨 변경
```

## 오브 종류
| 종류 | 색 | 점수 | 효과 |
|---|---|---|---|
| 일반 | 🔵 시안 | +10 | 콤보 유지 |
| 레어 | 🟡 골드 | +50 | 젬 +1, 슬로모션+플래시 |
| 폭탄 | 🔴 레드 | -0 | 탭 시 콤보 리셋, 화면 붉은 플래시 |

## Balance Table (초기값, `config.js` 반영)
| 항목 | 값 |
|---|---|
| 세션 길이 | 60s |
| 스폰 인터벌 | 0.55s → 60s동안 선형으로 0.28s로 감소 |
| 일반 낙하 속도 | 210 px/s → 340 px/s (난이도 상승) |
| 레어 출현 확률 | 6% |
| 폭탄 출현 확률 | 8% (세션 후반 12%) |
| 콤보 윈도우 | 직전 탭 이후 0.6s |
| 콤보 배율 | min(1 + combo*0.05, 3.0) |
| 등급 컷 | C<5k / B<15k / A<35k / S≥35k |
| 세션 보상 코인 | floor(score / 100) |
| 레어 탭 젬 | 1 |

## Monetization

### 재화
- **코인 (소프트)** — 플레이로 획득. 스킨 구매엔 사용 안 함 (밸런스 위험).
- **젬 (하드)** — 레어 오브 + IAP 구매. 코스메틱·부스터 구매에 사용.

### 카탈로그 (shared/iap/catalog.js)
- 젬 패키지 3종 (Small/Medium/Large)
- 스킨 2종 (Neon — 젬 300 / Galaxy — $4.99)
- 시즌 패스 (30일, $2.99)

### 전환 후크
- 레어 오브에서 젬을 맛보게 → "조금만 더 있으면 Galaxy 스킨 살 수 있는데"
- 결과 화면의 "이번 세션 최고기록 경신!" 뱃지 → 친구 공유(향후)
- 첫 구매 보너스 +100%: 모든 젬 패키지 첫 구매에 2배 지급 (1회)

### 수익 윤리
- 광고 없음 — 세션 집중 보호
- P2W 지양 — 스킨은 점수에 영향 없음
- 시즌 패스는 **시간만 투입해도 보상 트랙 절반 이상** 획득 가능

## Retention
- **데일리**: 첫 로그인 시 소량 젬. 연속 7일 시 스킨 조각(향후 구현)
- **주간**: 최고 스코어 갱신 배지 (프로필 저장)

## Non-Goals (MVP)
- 친구 리더보드, 서버 저장, 푸시 알림 (로드맵에서 shared 인프라와 함께 단계적으로)
