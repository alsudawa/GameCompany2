# KING SHOT — 기획 문서

## 한 줄 소개
드래그로 기사 왕을 움직여 몰려오는 적을 자동 사격하는 1분 내외의 중세 판타지 아레나 슈터.

## 코어 루프
1. 메뉴에서 5스테이지 중 하나 선택 → 카운트다운 3-2-1-GO
2. 4 일반 웨이브 + 1 보스 웨이브 — 적은 위/측에서 내려오고 왕에게 접근
3. 손가락 드래그 → 왕이 따라 이동(아레나 하단 1/3로 클램프)
4. 활시위는 자동으로 가장 가까운 적을 조준 사격
5. 웨이브 사이 양피지 두루마리 카드 3장 중 1장 선택 → 즉시 강해짐
6. 보스 처치 시 슬로모 + 황금 비 + 결과 화면(방패 메달 등급 S/A/B/C)

## 점수 / 등급
- 적 처치: 기본 점수 × (1 + 콤보×0.08, 최대 5×)
- 콤보 등급: GLORY!(5) → VALOR!(12) → TRIUMPH!(20) → CONQUEROR!(35) → LEGEND!(60)
- 등급컷: S 8000 / A 4500 / B 2000 / 그 외 C
- 결과 화면 방패 메달 색상: S 골드 / A 실버 / B 브론즈 / C 우드

## 진행/저장
- 베스트 스코어는 `bestScores['king-shot-<stageId>']` (스테이지별) + `bestScores['king-shot']` (전체)
- 젬은 GOLDEN 처치/보스 처치/픽업 자석으로 획득 → `Storage.addGems`
- 코인은 일반 처치 12% 확률 / 보스 처치 30개 → `Storage.addCoins`
- 모든 게임 공유 프로필(`gc2:profile`)에 저장 — Idle Studio에서 메타 연동 예정

## 수익 (포트폴리오 가정)
