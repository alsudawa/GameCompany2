# KING SHOT — QA / 테스트 체크리스트

## 환경
- 로컬: `python3 -m http.server 8000` → `http://localhost:8000/games/02-king-shot/index.html`
- 브라우저: Chrome / Safari / mobile WebKit (touch)

## 진입 흐름
- [ ] 런처(`index.html`) TITLE 002 카드 KING SHOT 클릭 → 메뉴 진입(페이드 인)
- [ ] 메뉴 BGM 재생됨(첫 입력 후 — autoplay 정책)
- [ ] 좌측 LAUNCHER 링크 클릭 → 런처 복귀
- [ ] 메뉴 → 좌/우 화살표 → 5스테이지 캐러셀 슬라이드
- [ ] 각 스테이지 카드에 스테이지명, 태그라인, 미니 프리뷰, BEST 점수 표시
- [ ] START 버튼 → 카운트다운 3-2-1-GO → 게임 시작

## 인-게임 컨트롤
- [ ] 화면 어디든 드래그 시 왕이 따라 이동
- [ ] Y는 하단 ~1/3로 클램프(상단 진입 못함)
- [ ] X는 좌우 돌담을 넘지 않음
- [ ] `pointerup`/`pointerupoutside` 모두 드래그 해제 — 화면 밖에서 손 떼도 왕이 표류하지 않음
- [ ] 멀티 터치(모바일): 마지막 활성 포인터를 따라감

## 자동 사격
- [ ] 적이 화면에 있을 때 가장 가까운 적을 자동 조준
- [ ] 적이 없을 때 사격 안 함(쿨다운 남아있다 발사)
- [ ] 활시위 진동 + 왕 미세 리코일 트윈 동작
- [ ] 화살이 속도 벡터 방향으로 회전, 갈색 잔상 도트 소량 페이드
- [ ] 멀티샷 +1 후 두 발이 살짝 스프레드되어 발사

## 적 5종
- [ ] GOBLIN — 1HP 흔하게 등장
- [ ] WOLF — 좌우 흔들리며 빠르게 접근
- [ ] ORC — 큰 방패, 정면(위쪽) 화살 데미지 절반
- [ ] SKELETON ARCHER — 화면 ~55% 지점 정지 후 1.6s마다 적 화살 발사
- [ ] GOLDEN KNIGHT — 후광 펄스, 처치 시 GEM 2개 드롭(자석으로 흡수)
- [ ] 모든 적의 눈이 왕 위치를 추적(Skeleton 제외 — 정적 눈구멍)

## 충돌 / 데미지
- [ ] 화살 명중 시 노란 스파크 + "-N" popText
- [ ] 크리티컬은 "CRIT!" 골드 텍스트 + 데미지 ×2
- [ ] 적 처치 시 회색 연기 3퍼프 + 황금 "+N"
- [ ] 적이 왕에 닿으면 0.6초 쿨다운으로 1 데미지(같은 적 중복 데미지 방지)
- [ ] 적 화살이 왕에 맞으면 1 데미지
- [ ] 데미지 입을 때 빨간 플래시 + 카메라 셰이크 + 콤보 끊김
- [ ] HP 하트 아이콘 채움 상태 정확히 갱신
